Классификация змей: Ядовитые vs Неядовитые

Использование Deep Learning и YOLOv8

Автор проекта: Али Дуйсен

Трек: Vision Detection / Classification

Постановка задачи и Данные

  • Главная цель: Создать модель, способную по фото определить, опасна змея или нет (safe / hospital).
  • Источник данных: Датасет snake-dataset-india.
  • Объем данных: Около 2000 изображений.
  • Разделение: Обучающая выборка (1775 фото) и тестовая (269 фото).

Исследовательский анализ (EDA)

  • Баланс классов: Наблюдается небольшой перевес в сторону опасных змей.
  • Класс Venomous (Ядовитые): 1201 изображение.
  • Класс Non-Venomous (Неядовитые): 843 изображения.
  • Подготовка (Препроцессинг): Ресайз изображений до 224x224 и применение аугментации для защиты от переобучения.

Методология и Обучение

Для эксперимента были выбраны две архитектуры из семейства YOLO:

  • YOLOv8n (Nano): Быстрая, легкая модель. Отличный базовый уровень (baseline).
  • YOLOv8m (Medium): Более глубокая архитектура, требующая больше ресурсов, но потенциально более точная.

Оборудование: Обучение проводилось на GPU T4.

Длительность: 40 эпох.

Результаты тестирования

Модель YOLOv8m показала наилучший результат:

  • Accuracy (Точность): 89.2% (против 88.5% у Nano)
  • F1-Score: 0.891

Анализ ошибок: Основная трудность для нейросети — мимикрия, когда неядовитые змеи маскируются под ядовитых схожим окрасом.

Выводы и Будущее проекта

  • Итог: Deep Learning отлично справляется с классификацией змей даже на небольших датасетах.
  • Чему научился: Работе с данными, обучению моделей YOLO, сравнению метрик и выбору оптимального решения.
  • Планы на будущее:
    • Добавить функцию Predict для тестирования на любых фото из интернета.
    • Обучить модель на данных из других регионов для универсальности.
